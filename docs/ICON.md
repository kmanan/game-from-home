# Game From Home icon

The mark combines a home roof with a controller, in coral orange and ivory on a charcoal rounded tile. The exterior is transparent. The master is generated raster artwork; no vector master is claimed.

## Files

- `assets/app-icon.png`: original final artwork, 1254 × 1254 RGBA PNG.
- `assets/app-icon.ico`: Windows icon containing 16, 20, 24, 32, 40, 48, 64, 96, 128, and 256 px sizes.
- `../src/GameFromHome/Assets/App.png`: compact PNG for UI previews.

Artwork generated with the built-in image-generation tool, followed by one cleanup edit. ICO and preview files are format/size exports of the final artwork. The generated artwork retains subtle tonal variation; the flat UI accent is defined separately in SPEC.md.

## Original prompt

Create one polished Windows desktop app icon for an application named Game From Home. Icon only, absolutely no text, letters, labels, watermarks or mockup presentation. A single strong geometric symbol combining a simple house roof with a compact game controller as the body of the house, conveying leaving work behind and playing at home. Premium friendly utilitarian design, crisp vector-like edges, minimal two-tone palette: warm vivid coral-orange symbol on a deep charcoal rounded-square tile. Small ivory controller details: one plus D-pad and two simple dots. Keep very few elements and thick shapes readable at 24 pixels. Flat graphic, no 3D, no glossy effects, no extraneous background illustration, no circuits, no lightning bolt. Center the tile with generous balanced internal padding. Square 1024x1024 composition, rounded tile isolated on a genuinely transparent outer background. The symbol must feel like a coherent custom app mark, not a stock controller pasted on a house.

## Final edit prompt

Polish this app icon, preserving its exact roof-and-controller silhouette, coral-orange mark, ivory D-pad and two dots, dark rounded-square tile and overall layout. Remove the irregular dark/transparent smudge or hole at the lower center under the controller. The entire tile must be fully opaque, uniform solid charcoal with no gradients, shadows, texture, holes or blemishes. Make the orange and ivory shapes perfectly flat solid colors too, while preserving smooth antialiased edges. Only the exterior outside the rounded-square tile should be transparent. No text, no added elements. This is a precise cleanup for a production Windows app icon.
