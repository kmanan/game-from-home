# Brand and sharing assets

- `assets/app-icon.png`: 1254 × 1254 raster app icon with transparent exterior.
- `assets/app-icon.ico`: Windows icon with multiple sizes.
- `assets/app-screenshot.png`: native app screen.
- `assets/social-preview.png`: 1280 × 640 GitHub preview, under 1 MB.

The icon and social card were made with the built-in image-generation tool, followed by format/size export. The brand combines a home roof and controller in charcoal, coral, and ivory. Third-party app icons in the screenshot remain their owners' marks.

The social prompt requests exact text: “WINDOWS UTILITY”, “Game From Home”, “Make room for play.”, “Clean app exits. More available RAM.”, and “Open source · On demand”. It uses the app icon as reference, opaque charcoal, generous safe margins, and a 2:1 layout. It claims no performance figures.

For repository link previews, upload `social-preview.png` in Settings → Social preview. Verify the public page's `og:image` and `twitter:image` metadata after saving. Sharing services may cache earlier previews.

`design-prototype.fragment.html` preserves the original interactive design fragment. It uses its host visualization environment and simulated app data; the Windows app screenshot shows the delivered native UI.
